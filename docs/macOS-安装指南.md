# 在 Mac 上安装 FCL（超详细版）

> 这份说明是给**第一次在 Mac 上安装非 App Store 软件**的人写的。
> 请按顺序一步一步做，每一步都写了"应该看到什么"和"如果不对怎么办"。
> 全程大约 5 分钟。

## 第 0 步：确认你的 Mac 芯片

不同芯片要下不同的包，**下错会打不开**。

1. 点屏幕**左上角的 **
2. 选 **「关于本机」**
3. 在弹出的小窗口里找 **「芯片」** 这一行：

| 你看到的 | 说明 | 你要下载 |
| --- | --- | --- |
| `Apple M1` / `M2` / `M3` / `M4` / `M5` / 以后更数字 | Apple 自研芯片 | **arm64** 版 |
| `Intel Core i5` / `i7` / `i9` | 老款 Intel 芯片 | **x64** 版 |

> 记不住也没关系：装错版本时 Mac 会提示"无法打开"或直接闪退，换另一个包重来即可，不会损坏系统。
>
> **系统版本要求**：需要 **macOS 12 Monterey 或更新**（因为内置的 Electron 43 需要这个版本）。

---

## 第 1 步：下载（最关键，先看这一段）

打开 Releases 页面：**https://github.com/Him-Wang/FCL/releases**

找到标题是 **「FCL 1.0.1 for macOS」** 的那个（不是 1.0.0）。

在它下面的 **Assets** 列表里点文件名下载：

| 你的芯片 | 下载这个 |
| --- | --- |
| Apple M 系列 | `FCL-1.0.1-mac-arm64.dmg` |
| Intel | `FCL-1.0.1-mac-x64.dmg` |

> **文件很大（约 120 MB）**，取决于网速可能要几分钟。
> 下载过程中**不要关掉浏览器、不要合盖休眠**，否则会断。

**如果 GitHub 打不开或下载很慢**：可以先下 `.zip` 那个（同样位置，名字以 `.zip` 结尾），它和 dmg 内容一样。

### ⚠️ 千万不要做的事

- ❌ **不要把下载中的文件拖到「应用程序」**
- ❌ 不要双击名字后面带 `.download` 的文件
- ❌ 不要试图"打开 dmg 文件本身"就完事 —— dmg 是安装包容器，要先打开它，再把里面的 **FCL** 拖出来

> 之前有人把 `FCL-1.0.0-mac-arm64.dmg.download`（**没下完的临时文件**）拖进了「应用程序」，那当然打不开。下面第 2 步就是检查这个。

## 第 2 步：确认下载真的完成了

打开「访达」（Dock 上左数第一个笑脸图标），点左边的 **「下载」**。

看文件名结尾：

| 文件名 | 含义 | 能不能用 |
| --- | --- | --- |
| `FCL-1.0.1-mac-arm64.dmg.download` | **还在下载**（或被中断） | ❌ 不能用 |
| `FCL-1.0.1-mac-arm64.dmg` | 下载完成 | ✅ 可以用 |

**看不到 `.download` 才算下载完。**

### 更保险的确认方法

1. 在「下载」里**单击选中**这个文件（不要双击）
2. 按 **`Command + I`**（或右键 → 显示简介）
3. 看「简介」窗口里的两项：

| 项目 | 应该是 |
| --- | --- |
| **大小** | 约 **120 MB**（110–130 MB 之间都正常）。如果只有几 MB 或 0 字节 → 没下完 |
| **种类** | 「磁盘映像」（dmg）或「应用程序」（app）。如果是「文稿」→ 文件不对 |

### 如果一直卡在 `.download`

1. 把这个 `.download` 文件删掉（拖到废纸篓）
2. 回到浏览器**重新下载**，等它自己变成普通文件名
3. 还是不行就换网络（手机热点也行），或者改用 `.zip` 包

## 第 3 步：打开 dmg，把 FCL 拖进「应用程序」

1. **双击**下载好的 `FCL-1.0.1-mac-arm64.dmg`
   - 会弹出一个小窗口，里面有两个图标：
     - 左边：**FCL**（黑色小鱼图标，就是启动器本体）
     - 右边：**「应用程序」**（一个文件夹图标，旁边有个箭头）
2. **按住左边的 FCL 图标，拖到右边的「应用程序」图标上，松手**
   - 这时会有一个"复制"进度条，几秒钟
3. 复制完成后，把这个小窗口关掉
4. 在访达左侧「位置」里找到刚挂载的 **FCL**（带一个像光盘的图标），点它右边的小 ⏏ 按钮（推出），或者右键 →「推出」

> ✅ 完成标志：打开「访达 → 应用程序」，能看到一个 **FCL**（黑色小鱼图标，没有问号、不是白纸）。

### 如果这一步出错

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 双击 dmg 提示「无法打开，来自身份不明的开发者」 | dmg 也带隔离标记 | 右键 dmg →「打开」；或先执行 `xattr -dr com.apple.quarantine ~/Downloads/FCL-1.0.1-mac-arm64.dmg` 再双击 |
| 拖进「应用程序」时提示「需要输入密码」 | 你用的不是管理员账户 | 输入管理员密码，或换管理员账户操作 |
| 拖进去后图标是白纸/问号，名字结尾 `.download` | **拖错了文件** —— 你把没下完的临时文件拖进去了 | 删掉它，回到第 1 步重新下载，按第 2 步确认后再拖 |

## 第 4 步：第一次打开（会被系统拦一次）

FCL 没有向苹果付费购买开发者证书（$99/年），所以 macOS 第一次会拦住它。**这是所有非 App Store 软件都会遇到的，不是病毒。**

### 方法 A：右键打开（macOS 12 / 13 / 14 适用）

1. 打开「访达 → 应用程序」
2. **右键点 FCL**（触控板：双指轻点；或按住 `Control` 再点一下）
3. 菜单里选 **「打开」**
4. 弹出对话框写"无法验证开发者" → 点 **「打开」**
5. 以后就能正常双击了

### 方法 B：系统设置里放行（macOS 15 / 26 及以后必须用这个）

新版 macOS 已经**取消了右键打开**的绕过方式，第一次要这样：

1. 在「应用程序」里**双击 FCL** → 会弹出"无法打开"
2. 点 **「好」**（或「取消」），关掉弹窗
3. 点左上角  → **「系统设置」**
4. 左侧点 **「隐私与安全性」**
5. 右侧**一直往下滚到最底部**
6. 会看到一行：
   > 已阻止使用「FCL」，因为来自身份不明的开发者。
   点旁边的 **「仍要打开」**
7. 输入你的**开机密码**，回车
8. 再回「应用程序」双击 FCL → 这次会再问一次，点 **「打开」**

> ✅ 完成标志：FCL 窗口出现（标题栏写着 FCL · FishCraftLauncher）。以后直接双击就行。

## 第 5 步：如果提示「已损坏，无法打开」

原文一般是：

> "FCL" 已损坏，无法打开。你应该将它移到废纸篓。

**99% 不是文件真坏了**，而是浏览器给下载的文件加了"隔离标记"（quarantine）。删掉这个标记即可。

### 操作步骤（一步一步来）

1. 按 **`Command + 空格`**，输入 `终端`（英文系统输入 `Terminal`），回车
   - 会打开一个白底或黑底的窗口，里面有一行提示符
2. **复制**下面这一整行：

```bash
xattr -dr com.apple.quarantine /Applications/FCL.app
```

3. 回到终端窗口，按 **`Command + V`** 粘贴，然后按 **回车**
   - 正常情况：**没有任何输出**，光标回到下一行提示符（这就是成功）
   - 如果提示 `No such file` → 说明 FCL 没在「应用程序」里，回到第 3 步重新拖
   - 如果提示 `Operation not permitted` → 在命令前面加 `sudo `，回车后输入开机密码（输入时不显示字符）

4. 回到「访达 → 应用程序」，双击 **FCL**

> 如果仍然提示"已损坏"，说明**下载的文件不完整**（网络中断导致 dmg 损坏）。
> 删掉重新下载，并按第 2 步确认大小约 120 MB。

## 常见错误对照表

| 你看到的现象 | 真正的原因 | 解决 |
| --- | --- | --- |
| 「应用程序」里图标是白纸/问号，名字带 `.download` | 拖进去的是**没下完的安装包** | 删除 → 重新下载 → 第 2 步确认 → 再拖 |
| 「FCL 已损坏，应该移到废纸篓」 | 隔离标记 / 下载不完整 | 第 5 步的 `xattr` 命令；仍不行就重下 |
| 「无法验证开发者」且没有「打开」按钮 | macOS 15+ 的 Gatekeeper | 第 4 步方法 B（系统设置 → 隐私与安全性 → 仍要打开） |
| 双击后图标在 Dock 跳一下就没反应 | 架构不匹配（Intel 包跑在 M 芯片上，或反之），或系统版本过低 | 第 0 步重新确认芯片，换另一个包；确认 macOS ≥ 12 |
| 打开后窗口一片空白 | 显卡/合成器问题 | 到设置里把"背景不透明度"拉到 100% 再试；仍不行发日志 |
| 能开但"部署 Java"卡住 | 访问不到 `api.adoptium.net` | 检查代理；或 `brew install --cask temurin` 后手动指定 Java 路径 |
| 微软账号登录失败 | 微软的跨站策略 | 用登录窗口下方的「浏览器登录」兜底；或先用离线账号 |

## 怎么找日志 / 怎么卸载 / 怎么更新

### 找日志（报错时先给我这个）

在终端里执行：

```bash
open "$HOME/Library/Application Support/FCL-Portable/logs"
```

会打开日志文件夹，里面的 `app.log` 就是日志。
也可以直接在访达里按 `Command + Shift + G`，粘贴：

```
~/Library/Application Support/FCL-Portable/logs
```

### 数据都存在哪

```
~/Library/Application Support/FCL-Portable/
├── data/    设置、账号、皮肤库
├── game/    游戏本体、存档、模组、材质包
├── java/    一键部署的 Java
├── logs/    日志
└── temp/    临时文件
```

> 存档在 `game/saves/`，搬家时把这整个文件夹拷走就行。

### 彻底卸载

1. 打开「访达 → 应用程序」，把 **FCL** 拖到废纸篓
2. 在访达里按 `Command + Shift + G`，粘贴 `~/Library/Application Support/`，回车
3. 找到 **FCL-Portable** 文件夹，删掉

（不写注册表、不装后台服务，删这两处就干净了。）

### 更新到新版本

1. 下载新版本的 dmg
2. 双击打开，把里面的 FCL 拖进「应用程序」
3. 弹出"已存在同名项目"时选 **「替换」**

数据在 `~/Library/Application Support/FCL-Portable/`，**不会被覆盖**，账号、版本、存档都还在。
