# FCL 构建 / 发版备忘（国内网络）

记录 2026-10-26 发 v1.3.10 时踩的坑，下次发版可直接照做。

## 1. 安装依赖

GitHub 直连经常超时，Electron 二进制走镜像：

```powershell
$env:TEMP = "<项目>\..\build-tmp"; $env:TMP = $env:TEMP
$env:ELECTRON_CACHE = "$env:TEMP\electron-cache"
$env:ELECTRON_BUILDER_CACHE = "$env:TEMP\eb-cache"
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"

node <npm-cli.js> install --no-audit --no-fund --cache <项目>\.npm-cache
```

## 2. 打包

```powershell
node node_modules\electron-builder\cli.js --win --x64 "-c.electronDownload.cache=$env:TEMP\electron-cache"
```

两个必踩的点：

- **`EPERM: mkdir %TEMP%\eb-dl-*.lock`** —— 打包器默认往系统临时目录写锁文件，改成项目内 `TEMP` 即可。
- **`EPERM: mkdir %LOCALAPPDATA%\electron\Cache`** —— `ELECTRON_CACHE` 对 electron-builder 不生效，必须用 `-c.electronDownload.cache=<路径>` 显式覆盖，否则 Electron 已经下载完了还是会前功尽弃。

产物在 `dist\FCL-<version>-x64.exe`，顺手算哈希：

```powershell
(Get-FileHash dist\FCL-1.3.10-x64.exe -Algorithm SHA256).Hash
```

## 3. push 失败时的提交办法

`git push` 报 `Recv failure: Connection was reset` / `Failed to connect to github.com:443`，但 `gh api` 是通的（走 api.github.com），可以直接用 Git Data API 提交：

1. `POST /repos/{owner}/{repo}/git/blobs`，body `{"content":"<base64>","encoding":"base64"}`
2. 取当前 main 的 tree：`GET /git/commits/{sha}` → `.tree.sha`
3. `POST /git/trees`，带 `base_tree` + 改动文件列表
4. `POST /git/commits`，带 `message` / `tree` / `parents`
5. `PATCH /git/refs/heads/main`，body `{"sha":"<new commit>","force":false}`

**坑**：Windows PowerShell 的 `Out-File -Encoding utf8` 会写 BOM，GitHub 直接回 `Problems parsing JSON`。
用 `[System.IO.File]::WriteAllText($path, $json)` 或 `-Encoding ASCII`，JSON 里全 ASCII 时最稳。

## 4. 建 tag 和 release

远端 tag（轻量）也能纯 API 建，不用 push：

```
POST /git/refs   {"ref":"refs/tags/v1.3.10","sha":"<commit>"}
```

release + 附件上传 `gh` 能用就别走 API：

```powershell
gh release create v1.3.10 "dist\FCL-1.3.10-x64.exe" --title "FCL 1.3.10 · Windows" --notes-file release-notes.md
```

上传后核对 `digest` 是否等于本地 SHA256：

```powershell
gh release view v1.3.10 -R Him-Wang/FCL --json assets
```
